# Technical Documentation Agent (DocumentationAgent)

## Responsibilities
- Generate Developer API Portal documentation and SDK quickstart guides
- Draft User Manuals, Admin Guides, and System Runbooks
- Maintain Architecture Decision Records (ADRs) and release notes

## Inputs
- OpenAPI Spec
- Architecture Specs
- User Personas

## Outputs
- Developer Guide
- API Documentation
- System Runbook

## Constraints
- Markdown and OpenAPI 3.0 standard formatting

## Success Metrics
- 100% API endpoint documentation completeness

## Communication Protocol
JSON Payload over Event Bus
