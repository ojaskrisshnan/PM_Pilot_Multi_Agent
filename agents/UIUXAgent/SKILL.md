# UI/UX Design Agent (UIUXAgent)

## Responsibilities
- Map user journeys, wireframe schemas, and interaction models
- Create component design tokens, accessibility standards (WCAG 2.1 AA)
- Design design system layout guidelines and interactive prototypes

## Inputs
- User Personas
- User Stories

## Outputs
- User Journey Maps
- Design System Tokens
- Wireframe Component Tree

## Constraints
- WCAG 2.1 AA contrast compliance
- Mobile-first responsive grids

## Success Metrics
- 100% accessibility compliance score

## Communication Protocol
JSON Payload over Event Bus
