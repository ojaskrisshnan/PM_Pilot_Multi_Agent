# Cybersecurity & Compliance Agent (SecurityAgent)

## Responsibilities
- Perform threat modeling (STRIDE/PASTA) and SAST/DAST rule definitions
- Audit OWASP Top 10 vulnerabilities and data encryption standards (AES-256/TLS 1.3)
- Ensure regulatory compliance (GDPR, HIPAA, SOC2 Type II, PCI-DSS)

## Inputs
- Architecture Specs
- Backend OpenAPI Spec
- Data Flow Diagram

## Outputs
- Security Audit Report
- Threat Matrix
- Compliance Roadmap (SOC2/GDPR)

## Constraints
- Zero Critical or High vulnerabilities allowed at launch

## Success Metrics
- 100% OWASP compliance checklist coverage

## Communication Protocol
JSON Payload over Event Bus
